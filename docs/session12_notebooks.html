Tutorial: Fitting data with uncertainties on both axes#

So far we have only considered errors in the dependent variable (y-axis). We used a standard least square regression. If we have uncertainties (errors) in both independent (x-axis) and dependent (y-axis) variable, we will need to use a method called weighted Orthogonal Distance Regression (ODR) or Total Least Squares. ODR minimises the perpendicular (orthogonal) distance from the data points to the fitted curve.

To use ODR you need to install the following package by executing the cell below.

!pip install odrpack

Note: Currently, ODR is still part of Scipy, but it will be removed in a future release. Therefore, we use the new package odrpack in this course.

Task 3#

Using odr_fit() determine the resistance \(R\) with uncertainties.

The syntax is

sol = odr_fit(f, xdata, ydata, beta0,
              weight_x=weight_x, weight_y=weight_y)

  • f is your model function (e.g. Ohm’s law).

  • beta0 is the initial guess of your parameter to fit. For example, you can use the result for Task 1 or Task 2. For simple and linear models like Ohm’s law, the initial guess does not need to be precise but is crucial in complex non-linear models.

  • xdata and ydata are your measurements or data set.

  • weight_x and weight_y are your weights for your data set and are the inverse of the squared standard deviations (variance), e.g. weight_x = 1/sigma_x^2 and weight_y = 1/sigma_y^2.

from odrpack import odr_fit

To extract the parameter with uncertainties you use sol.beta and sol.sd_beta. If you want to inspect the co-variance matrix use sol.cov_beta.

Note: There is no scaling of your co-variance matrix. Your errors must represent the true uncertainties.

Follow the link for more details on the input and outputs of odr_fit().

print(sol.beta, sol.sd_beta)

Plot your best fit function and data points with error bars on both axes including legend plus axes labels and compare the result with Task 1 and 2.

Task 4#

As you might have noticed the data set from diffusion.csv contains uncertainties for diffusion \(D\) and temperature \(T\). The parameters we would like to fit are the material dependent constant \(D_0\) and activation energy \(E_A\).

When using odr_fit() it is advantageous that multiple parameters are provided as an array.

def arrhenius_equation(T, beta):
    """
    Calculates the diffusion using the Arrhenius equation.
    Args:
        T : temperature in Kelvin
        beta : parameters, beta[0] = D_0 and beta[1] = E_A
    """
    k_B = 1.38e-23 # Boltzmann constant in J/K
    D_0, E_A = beta
    D = D_0* np.exp(-E_A/k_B/T)
    return D

Determine \(D_0\) and \(E_A\) using odr_fit(). Plot the best fit and data points with error bars including legend and axes labels.

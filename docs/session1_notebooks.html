Tutorial: Calculations, variables and help#

To open the tutorial hover with your mouse over the rocket symbol at the top of your browser, so that Colab appears. Click on it and the tutorial will open in Colab. See also Executing Jupyter Notebooks on Colab. The tutorial is also called a Jupyter Notebook. It consist a text cells (like here) and code cells (see below).

Before you can execute a code cell you need to save the notebook on your google-drive. Code cells can be executed by hovering over the cell and clicking circle with a triangle on the left hand side. Alternatively , you can select a the cell by clicking on it and use the keyboard shortcut Ctrl+Enter (Windows/Linux) or Command+Enter (MacOS). To edit the code or text cell, just select or double click it and start editing.

Defining, assigning and manipulating variables#

Variables are used for storing data that can be referenced and manipulated throughout a programme. A variable is essentially a name that is assigned to a value. To assign a value to a variable the assignment operator = is used. This is not a mathematical operation.

When defining variables, make sure you do not use variables with spaces, or variables that start with a number. Avoid key words like sin, cos, exp, mean, print etc.

a = 2
b = 3
a + b

After executing the code cell above you have defined the variables a and b with the values 2 and 3, respectively. If you click on {} variables icon at the bottom left, a tab on your right hand side will open, which shows the properties of your variables.

Checking your variables can be very helpful when debugging your programme code and searching for errors.

To show or print a variable or specific output use the print() function. Similar to a mathematical function like \(f(x)\) the arguments or inputs to a function are given inside () as show in the example below.

print(a, b)
print(a + b)

Importing additional packages#

Python is a versatile, high-level programming language. It provides many packages and libraries and is used in a wide range of applications, including web development, data science, machine learning, and automation. Depending on your Task you only import the necessary packages.

For example, for mathematical calculations, simulations, matrix operations (linear algebra) or fitting data the NumPy packages if often used. To import a packages use the following line:

import numpy as np

NumPy is usually imported as np, which is shorter than writing numpy every time. This is a widespread convention while distinguishing NumPy features from others that have the same name like built in function mean() and NumPy’s np.mean(), which provides more options and is designed to handle arrays.

To take the logarithm of the number 10 you would use the following line of code:

np.log(10)

Help functions#

Is this the expected result? Try using the help function to better understand what the log function does.

# Quick help
np.log?
# More extensive help
help(np.log)

As you can see the np.log() function is used to calculate the natural logarithm \(\ln\) (). To calculate the logarithm in base of 10 the np.log10() function is used.

Operations on variables#

In Task 1 you defined a variable myVar. You can then use this variable to perform different operations on

print(myVar+3)               # adding
print(myVar*2)               # multiplying
print(myVar/myVar)           # dividing 
print(myVar**2)              # squaring (order of 2)
print(np.sqrt(myVar))        # square rooting         
print(np.log(myVar))         # ln of a value
print(np.log10(myVar))       # log in base 10

Python uses the order of BODMAS (brackets, order(power), divide, multiply, addition and subtraction).

Clearing your session#

As you keep going your workspace (session) will get full of variables, imported packages, …, which uses up resources. Some you want to keep, others you might not. In other instances you might have accidentally overwritten a build in function like print() by defining a variable called print or would like to stop the execution of a code cell. In those cases you can restart session by clicking on the runtime tab at the top of your browser and select the desired option. Here you are also able to run all cells or selected cells without executing them individually.

Note: if you restart your session you need to import packages like numpy again to make them available.

At the bottom left panel of your colab session, you notice a ribbon called “Variables”. If you click on it, you will see information about your variables, which can be very helpful while debugging your code.

Trigonometry#

The value of pi is built into numpy. Trigonometric functions use radians. Degrees need to be converted to radians either 90/360*2*np.pi or using the numpy function np.deg2rad().

x = np.pi                    # assigns pi to x
print(x)
print(np.cos(x))             # note uses radians
print(np.sin(x))
print(np.tan(x))              
print(np.arctan(x))          # inverse tan
x = 90   
print(np.cos(np.deg2rad(x))) # cos assuming x is in degrees

Limitations of Python#

Python and most other programming languages have limitations regarding the largest/smallest number and precision.

y = 1e307                   # a large number
print(y, y*100)             # too large for Python (inf is infinity)
y = 1e-322                  # a small number 
print(y, y/100)             # too small for Python to read (so reads 0)
print(np.finfo(float).eps)  # the smallest number Python can 'see' between two values

Multiple entries on one line#

As the semi-colon tells Python that you have completed the line, you can put multiple entries on one line to save space.

a = 5; b = 4
print(a,b)
c = a + b
print(c)

Alternatively you can assign values to multiple variables in one line like this

a, b = 5, 8
print(a,b)
c = a + b
print(c)
